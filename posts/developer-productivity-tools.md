개발자의 하루는 코드를 작성하는 시간보다 **환경을 설정하고, 문서를 찾고, 반복 작업을 처리하는 시간**이 훨씬 많습니다. 좋은 도구를 갖추면 이 낭비를 줄이고 핵심 작업에 집중할 수 있습니다. 오늘은 실제로 매일 활용 중인 생산성 도구 5가지를 소개합니다.

---

## 1. Raycast — 맥의 런처를 대체하는 올인원 도구

macOS를 쓴다면 기본 Spotlight 대신 **Raycast**를 사용해 보세요. 단순한 앱 런처를 넘어 다음 기능들을 제공합니다.

- 클립보드 히스토리 검색 (최근 복사한 내용 바로 불러오기)
- GitHub PR / 이슈 빠른 검색
- 커스텀 스크립트 실행
- 계산기, 단위 변환, 색상 코드 변환

```
# Raycast에서 GitHub PR 열기
CMD + Space → "pr 42" 입력 → Enter
```

특히 **Window Management** 기능으로 화면 분할을 단축키로 처리하면 마우스를 잡을 일이 크게 줄어듭니다.

---

## 2. Warp — AI가 내장된 차세대 터미널

기존 터미널(iTerm2, Terminal.app)에서 **Warp**로 옮기면 생산성이 눈에 띄게 올라갑니다.

### 핵심 기능

| 기능 | 설명 |
|------|------|
| AI Command Search | 자연어로 명령어 검색 (`#` 입력 후 질문) |
| Block 단위 출력 | 명령어 결과를 블록으로 관리해 스크롤 없이 탐색 |
| 공유 가능한 퍼머링크 | 팀원에게 터미널 출력 결과를 링크로 공유 |
| 자동완성 | 명령어 히스토리 기반 스마트 제안 |

```bash
# Warp AI 검색 예시
# '#' 를 입력하면 AI 검색 모드 진입
# "3일 전에 수정된 파일 찾기" → find . -mtime -3 으로 변환
```

---

## 3. GitHub Copilot — 페어 프로그래밍 파트너

**GitHub Copilot**은 이제 선택이 아닌 필수에 가까워졌습니다. 단순히 코드를 완성해주는 것을 넘어 다음 상황에서 특히 빛납니다.

### 잘 활용하는 방법

1. **주석 주도 개발**: 먼저 주석으로 의도를 적으면 Copilot이 구현을 제안합니다.
2. **테스트 코드 생성**: 함수명 옆에서 `Tab`을 누르면 테스트 케이스를 자동 완성합니다.
3. **반복 패턴 탈출**: 보일러플레이트 코드를 빠르게 처리하고 비즈니스 로직에 집중합니다.

```typescript
// 주석만 작성하면 Copilot이 구현을 제안
// 사용자 이메일로 비밀번호 재설정 링크를 생성하고 이메일을 전송
async function sendPasswordResetEmail(email: string): Promise<void> {
  // Copilot이 여기서부터 코드를 채워줍니다
}
```

## 4. Obsidian — 개발 노트의 두 번째 뇌

개발자에게 문서화는 코딩만큼 중요합니다. **Obsidian**은 마크다운 기반의 로컬 노트 앱으로 다음과 같이 활용할 수 있습니다.

- 프로젝트별 TIL(Today I Learned) 기록
- 문제 해결 과정을 `[[링크]]`로 서로 연결
- Daily Note로 하루 작업 흐름 정리
- 코드 스니펫 저장소로 활용

```markdown
# TIL: React Query 캐싱 전략

## 문제
API 요청이 너무 자주 발생해 서버 부하 발생

## 해결
staleTime을 5분으로 설정해 캐시 재사용
→ [[React Query 심화]] 참고
```

모든 데이터가 로컬 마크다운 파일로 저장되므로 특정 플랫폼에 종속되지 않는다는 것이 큰 장점입니다.

---

## 5. Excalidraw — 손쉬운 기술 다이어그램 드로잉

아키텍처 설계나 팀 커뮤니케이션 시 복잡한 UML 툴 없이도 **Excalidraw**로 충분합니다.

- 손 그림 느낌의 자유로운 다이어그램
- 실시간 협업 지원
- VS Code 확장으로 IDE에서 직접 사용 가능
- 내보내기 시 SVG/PNG 지원으로 문서에 바로 삽입

## 마치며

도구는 목적이 아니라 수단입니다. 소개한 5가지 도구 모두를 한꺼번에 도입하려 하면 오히려 학습 비용이 생깁니다. **하나씩 천천히 익혀서 자신의 워크플로에 자연스럽게 녹아들도록** 하는 것이 핵심입니다.

가장 효과적인 순서를 추천하자면:

1. Warp (터미널 교체 — 즉시 효과)
2. Raycast (런처 교체 — 설정 후 자동화)
3. GitHub Copilot (코딩 생산성 — 익숙해지는 데 1~2주)
4. Obsidian (지식 관리 — 장기적인 투자)
5. Excalidraw (협업 시 필요에 따라)

좋은 도구를 갖추면 **반복적이고 지루한 작업에서 해방**되고, 정말 중요한 문제를 푸는 데 에너지를 집중할 수 있습니다.
